# Many Hats site — v10

This version incorporates the latest visual direction:
- Consistent navy navigation bar on every page.
- Gold underline on the currently selected navigation link.
- Prominent but restrained page labels: ABOUT, CAREERS, CONTACT, APPS.
- Official Many Hats logo used consistently.
- Supplied Many Hats baseball-cap and mailbox assets used on Careers and Contact.
- Home/About hero treatments use the official logo with surrounding hat accents.
- Home hero includes the subtle circular/ring background treatment from the approved mockup.
- Home hero background overlay is provided separately as `assets/home-background.svg` and applied as a transparent scalable layer.
- Existing Apps / That's in the Bible? pages remain linked with local relative paths.

Open `index.html` directly in a browser, or serve the folder with a local web server.


## Latest update
The Apps page hero now uses the new hat-grid phone visual supplied for the Apps redesign. The existing Home lightbulb and About hat-pyramid assets are preserved.
